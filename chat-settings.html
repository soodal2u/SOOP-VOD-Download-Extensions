채팅 오버레이 설정

현재 영상의 썸네일과 샘플 채팅으로 미리보기를 보여주고, 슬라이더와 숫자 입력으로 위치, 크기, 색상, 표시 밀도를 바로 조절할 수 있게 정리했습니다.

실시간 미리보기 현재 영상 기준으로 바뀐 설정이 즉시 반영됩니다.
자동 저장 조절한 값은 바로 저장되어 실제 ASS 생성에도 동일하게 적용됩니다.
직접 입력 지원 슬라이더 옆 숫자 칸에 직접 입력해서 빠르게 맞출 수 있습니다.

현재 영상 기준 프리뷰

현재 영상을 확인하는 중입니다.

샘플 채팅을 불러오는 중입니다.

현재 영상 썸네일을 찾지 못했습니다. 그래도 위치와 크기 설정은 계속 조절할 수 있습니다.

현재 시점: - 설정은 자동 저장됩니다.

프리셋

빠르게 시작하기

가장 가까운 결과를 먼저 고른 뒤 세부 항목만 조절하면 훨씬 빠릅니다.

`우측 중단 기본`은 FHD 게임 화면 오른쪽 중간 채팅 느낌에 맞춘 템플릿입니다.

표시

기본 표시 방식

제목과 배경 패널을 먼저 켜고 끄면서 전체 느낌을 결정합니다.

형식과 색상

문구와 유저 등급 색상

닉네임 형식과 등급별 색상을 먼저 맞추면 미리보기 분위기가 바로 달라집니다.

사용 가능한 치환자: `{nickname}`, `{message}`. 예시: `[{nickname}] {message}` 또는 `{nickname} : {message}`

롤링

표시 밀도와 갱신 속도

값이 낮을수록 더 자주 갱신되고, 줄 수가 많을수록 화면이 더 빽빽해집니다.

위치와 크기

채팅창 위치 조정

왼쪽과 위쪽 위치를 먼저 맞추고, 그 다음 가로와 세로 크기를 정리하면 편합니다.

글자

텍스트 크기

미리보기는 FHD 기준 결과를 현재 화면 크기에 맞춰 축소해서 보여줍니다.

안내

사용 팁

현재 영상 기준으로 작동하므로, 다른 영상에 맞추려면 팝업에서 다시 진입해야 합니다.

채팅 설정 버튼은 팝업에서 연 현재 영상 정보를 기준으로 동작합니다.
새 영상을 기준으로 조절하려면 해당 영상 페이지에서 팝업을 다시 열고 `설정` 버튼을 눌러 주세요.
