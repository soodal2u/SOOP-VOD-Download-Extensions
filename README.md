# SOOP VOD Downloader

[![Chrome Web Store](https://img.shields.io/badge/Chrome%20Web%20Store-SOOP%20VOD%20Downloader-4285F4?logo=googlechrome&logoColor=white)](https://chromewebstore.google.com/detail/soop-vod-downloader/gjodmjkcebohglhppopcejdgpaplpdac)
![Version](https://img.shields.io/badge/version-3.17.0-31c48d)
![Manifest](https://img.shields.io/badge/manifest-v3-111827)

SOOP VOD Downloader는 숲(SOOP, 전 아프리카TV)에서 제공하는 VOD를 더 편하게 다운로드하고, 다운로드한 영상을 병합할 수 있도록 만든 Chrome 확장 프로그램입니다.

- Chrome Web Store: [SOOP VOD Downloader Extension](https://chromewebstore.google.com/detail/soop-vod-downloader/gjodmjkcebohglhppopcejdgpaplpdac)
- 현재 버전: `3.17.0`
- Manifest: Chrome Extension Manifest V3
- 개발자 이메일: `soodalpie@gmail.com`

## 주요 기능

1. 광고 제거: SOOP 광고 API 서버 요청을 차단합니다.
2. VOD 다운로드: SOOP VOD의 `m3u8` 파일을 감지하고 다운로드합니다.
3. 영상 병합: 다운로드한 `playlist.m3u8` 파일을 하나의 MP4 파일로 병합할 수 있습니다.
4. 구간 저장: 원하는 시작/종료 구간만 지정해서 저장할 수 있습니다.
5. 화질 선택: 선택한 화질을 직접 저장, M3U8, FFmpeg CMD에 적용합니다.
6. 제목 포함 저장: VOD 제목을 파일명에 포함해서 다운로드할 수 있습니다.
7. 파트 표시: 파트별 재생 구간과 플레이어 타임라인 색상 표시를 지원합니다.
8. 자막 생성: 채팅 자막 `.ASS` 파일 생성과 파트별 분할을 지원합니다.
9. 자막 설정: 채팅 오버레이 위치, 크기, 색상, 표시 방식 등을 설정할 수 있습니다.
10. 구독플러스 다시보기: 구독플러스 다시보기 다운로드 흐름을 지원합니다.
11. 서버 재시작: 병합 서버 오류가 발생했을 때 사용자가 직접 재시작을 요청할 수 있습니다.
12. 병합 페이지: 여러 개의 `m3u8` 파일을 병합 페이지에서 동시에 처리할 수 있습니다.
13. 오디오만 저장: 영상 없이 소리만 `.m4a` 파일로 저장합니다. 구간 저장과 함께 사용할 수 있습니다.

## 사용 방법

1. SOOP VOD 페이지를 엽니다.
2. Chrome 확장 프로그램에서 `SOOP VOD Downloader`를 실행합니다.
3. 원하는 화질을 선택합니다.
4. `M3U8 다운로드`, `직접 저장`, `FFmpeg CMD`, `병합 페이지` 중 필요한 방식을 선택합니다.
5. 병합이 필요한 경우 병합 페이지에서 `playlist.m3u8` 파일을 업로드하거나 감지된 항목을 사용합니다.
6. 채팅 자막이 필요한 경우 `ASS 자막` 기능과 설정 페이지를 사용합니다.

## 병합 기능 안내

`m3u8` 파일을 병합하는 기능은 개발자가 운영하는 서버와 직접 연결되어 있습니다. 시간이 조금 걸리더라도 사용자가 별도 프로그램을 설치하지 않고 영상을 하나로 합칠 수 있도록 구성했습니다.

로컬에서 직접 병합하고 싶은 사용자는 확장 프로그램에서 제공하는 FFmpeg CMD를 사용할 수 있습니다. 이 경우 PC에 FFmpeg가 설치되어 있어야 합니다.

## 화질이 낮게 저장될 때

화질 설정이 `자동`으로 되어 있으면 가장 낮은 화질로 선택되는 경우가 있습니다.

화질이 낮게 다운로드된다면:

1. 화질 설정에서 `1080` 또는 원하는 화질을 직접 선택합니다.
2. SOOP VOD 페이지를 새로고침합니다.
3. 다시 다운로드를 시도합니다.
